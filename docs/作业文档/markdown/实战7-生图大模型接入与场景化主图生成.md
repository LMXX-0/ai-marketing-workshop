## 一、作业目标

文案有了，现在要给商品配一张“海外生活场景”的主图。生图模型比文本模型慢得多（常见需要十几秒到一分钟），所以必须采用**异步任务 + 前端轮询**的方式。完成后你应该能做到：

- 用 LLM 把中文场景建议扩写成专业的英文生图提示词（带光影、构图指令）；
- 对接文生图 API，下发异步任务并查询任务状态；
- 把生成结果下载到自己的服务器，避免图片链接过期；
- 前端用骨架屏占位，每 3 秒轮询一次，成功后展示场景主图。

> **提示：**生图通常**按张计费**，且速度较慢。调试时不要连续狂点，一次只生成一张，并且先把提示词看一遍再下发。

## 二、背景知识

### 2.1 为什么要异步

| 方式 | 流程 | 问题 |
| --- | --- | --- |
| 同步 | 前端发请求，后端一直等到生图完成再返回 | 请求容易超时，用户一直转圈，服务器连接被长期占用 |
| 异步（本次采用） | 后端先拿到任务号立刻返回；前端定时查询状态；完成后取结果 | 体验好，也方便展示进度和失败重试 |

### 2.2 一次完整的生图流程

```
前端 POST /api/images/generate
  └─ 后端：读取场景建议 → LLM 扩写英文提示词 → 向万相下发任务 → 保存 pending 记录 → 返回 assetId
前端每 3 秒 GET /api/images/tasks/:assetId
  └─ 后端：向万相查询任务状态
        运行中 → 返回 pending
        成功   → 下载图片到本地 → 更新记录为 done → 返回图片地址
        失败   → 更新记录为 failed → 返回错误原因
```

### 2.3 好的生图提示词长什么样

| 要素 | 示例 |
| --- | --- |
| 主体 | a matte black wireless earphone case as the hero product |
| 场景 | on a wooden table in a sunlit Scandinavian café |
| 光影 | soft golden-hour sunlight, gentle rim light |
| 构图 | rule of thirds, shallow depth of field, 45-degree angle |
| 镜头 | 85mm lens, f/1.8 |
| 风格与质量 | commercial product photography, photorealistic, high detail |
| 限制 | no text, no watermark, no logo |

### 步骤 2　后端：用 LLM 扩写英文生图提示词

```js
新建 server/src/services/imagePromptService.js：
import { chatCompletion } from './llmClient.js'

const SYSTEM = `You are a professional e-commerce photography art director and an AI image prompt engineer.
Turn the product information and scene idea into ONE English prompt for a text-to-image model.

Rules:
1. Output ONLY the prompt text. No quotes, no explanation, 60-110 words.
2. Cover these elements in order: subject (the product as the clear hero), scene and environment,
   lighting (e.g. soft golden-hour sunlight, rim light), composition (e.g. rule of thirds, shallow depth of field,
   45-degree angle), camera and lens (e.g. 85mm, f/1.8), style and quality
   (commercial product photography, photorealistic, high detail).
3. Place the scene in an overseas lifestyle context that fits the target audience.
4. Keep the product's real colors and shape according to the appearance description.
5. Do NOT include any text, logo, watermark, or close-up human faces.`

export async function expandImagePrompt({ product, scene }) {
  const a = product.aiAnalysis || {}
  const user = `Product: ${product.name}
Category: ${product.category || 'N/A'}
Target audience: ${product.audience || 'General consumers'}
Appearance: ${(a.visual_elements || []).join('; ')}
Selling points: ${(a.core_selling_points || []).join('; ')}
Scene idea (Chinese): ${scene}`

  const { content } = await chatCompletion({
    model: process.env.TEXT_MODEL || 'qwen-plus',
    messages: [{ role: 'system', content: SYSTEM }, { role: 'user', content: user }],
    temperature: 0.7,
    purpose: 'prompt',
  })
  const prompt = content.trim().replace(/^["']|["']$/g, '')
  console.log('[image-prompt] 场景：', scene)
  console.log('[image-prompt] 扩写后的提示词：', prompt)       // 提交物 1 要截这条日志
  return prompt
}
```

### 步骤 3　后端：对接万相异步生图

1. 新建 `server/src/services/imageService.js`，包含创建任务、查询任务、下载图片三个函数：

```js
import fs from 'fs'
import path from 'path'
import { randomUUID } from 'crypto'
import { UPLOAD_DIR } from '../middlewares/upload.js'
import { LLMError } from './llmClient.js'

const DS = 'https://dashscope.aliyuncs.com/api/v1'
const headers = (extra = {}) => ({
  Authorization: `Bearer ${process.env.DASHSCOPE_API_KEY}`,
  'Content-Type': 'application/json',
  ...extra,
})

// 1) 下发异步任务，返回 taskId
export async function createImageTask(prompt, size = '1024*1024') {
  const res = await fetch(`${DS}/services/aigc/text2image/image-synthesis`, {
    method: 'POST',
    headers: headers({ 'X-DashScope-Async': 'enable' }),     // 异步模式必须带这个请求头
    body: JSON.stringify({
      model: process.env.IMAGE_MODEL || 'wanx2.1-t2i-turbo',
      input: { prompt },
      parameters: { size, n: 1 },
    }),
  })
  const data = await res.json().catch(() => ({}))
  if (!res.ok || !data.output?.task_id) {
    throw new LLMError(`创建生图任务失败：${data.message || data.code || res.status}`)
  }
  return data.output.task_id
}

// 2) 查询任务：PENDING / RUNNING / SUCCEEDED / FAILED
export async function queryImageTask(taskId) {
  const res = await fetch(`${DS}/tasks/${taskId}`, { headers: headers() })
  const data = await res.json().catch(() => ({}))
  if (!res.ok) throw new LLMError(`查询任务失败：${data.message || res.status}`)
  const out = data.output || {}
  return { status: out.task_status, url: out.results?.[0]?.url, message: out.message || out.results?.[0]?.message }
}

// 3) 把结果图下载到本地（官方图片链接只保留 24 小时，必须自己存一份）
export async function downloadImage(url) {
  const res = await fetch(url)
  if (!res.ok) throw new LLMError('下载生成图片失败')
  const dir = path.join(UPLOAD_DIR, 'generated')
  fs.mkdirSync(dir, { recursive: true })
  const name = randomUUID() + '.png'
  fs.writeFileSync(path.join(dir, name), Buffer.from(await res.arrayBuffer()))
  return '/uploads/generated/' + name
}
```

**说明：**下载到本地还有一个好处：作业 8 打包 ZIP 时，图片与页面同源，不会遇到浏览器跨域限制。

### 步骤 4　后端：生图与任务查询接口

```js
新建 server/src/controllers/imageController.js：
import Product from '../models/Product.js'
import MarketingAsset from '../models/MarketingAsset.js'
import { expandImagePrompt } from '../services/imagePromptService.js'
import { createImageTask, queryImageTask, downloadImage } from '../services/imageService.js'

const TIMEOUT_MS = 5 * 60 * 1000

// POST /api/images/generate  { productId, sceneIndex }
export async function generate(req, res, next) {
  try {
    const { productId, sceneIndex = 0 } = req.body
    const product = await Product.findById(productId).catch(() => null)
    if (!product) return res.status(404).json({ code: 4004, message: '商品不存在' })
    const scene = product.aiAnalysis?.scene_suggestions?.[sceneIndex]
    if (!scene) return res.status(400).json({ code: 4001, message: '该商品没有场景建议，请先执行 AI 一键识别' })

    const prompt = await expandImagePrompt({ product, scene })
    const taskId = await createImageTask(prompt)
    const asset = await MarketingAsset.create({ productId, type: 'image', prompt, taskId, status: 'pending' })
    res.json({ code: 0, message: 'ok', data: { assetId: asset._id, prompt, scene } })
  } catch (e) { next(e) }
}

// GET /api/images/tasks/:assetId
export async function taskStatus(req, res, next) {
  try {
    const asset = await MarketingAsset.findById(req.params.assetId).catch(() => null)
    if (!asset) return res.status(404).json({ code: 4004, message: '任务不存在' })
    const reply = (extra = {}) => res.json({ code: 0, message: 'ok', data: { status: asset.status, imageUrl: asset.imageUrl, ...extra } })

    if (asset.status !== 'pending') return reply()
    if (Date.now() - asset.createdAt.getTime() > TIMEOUT_MS) {
      asset.status = 'failed'; await asset.save()
      return reply({ message: '生成超时，请重试' })
    }

    const r = await queryImageTask(asset.taskId)
    if (r.status === 'SUCCEEDED') {
      asset.imageUrl = await downloadImage(r.url)
      asset.status = 'done'; await asset.save()
      return reply()
    }
    if (r.status === 'FAILED') {
      asset.status = 'failed'; await asset.save()
      return reply({ message: r.message || '生图失败' })
    }
    reply()          // PENDING / RUNNING：仍在进行中，保持 pending
  } catch (e) { next(e) }
}
```

### 步骤 5　前端：骨架屏 + 每 3 秒轮询

```js
新建 client/src/api/image.js：

export const generateImage = (body) => http.post('/api/images/generate', body)
export const getImageTask = (assetId) => http.get(`/api/images/tasks/${assetId}`)
新建 client/src/views/SceneStudio.vue：
<script setup>
import { ref, computed, onMounted, onBeforeUnmount } from 'vue'
import { ElMessage } from 'element-plus'
import { useProductStore } from '../stores/product'
import { generateImage, getImageTask } from '../api/image'
import { fetchAssets } from '../api/asset'

const base = import.meta.env.VITE_API_BASE ?? ''
const store = useProductStore()
const productId = ref('')
const sceneIndex = ref(0)
const generating = ref(false)
const current = ref(null)           // { prompt, scene, imageUrl }
const gallery = ref([])

const ready = computed(() => store.list.filter((p) => p.aiAnalysis?.scene_suggestions?.length))
const product = computed(() => store.list.find((p) => p._id === productId.value))

let timer = null
let tries = 0
let busy = false                     // 防止上一次请求没回来又发下一次

function stopPolling() { clearInterval(timer); timer = null }

function startPolling(assetId) {
  stopPolling()
  tries = 0
  timer = setInterval(async () => {
    if (busy) return
    busy = true
    tries++
    try {
      const { data } = await getImageTask(assetId)
      if (data.status === 'done') {
        stopPolling(); generating.value = false
        current.value.imageUrl = base + data.imageUrl
        ElMessage.success('场景图生成完成'); loadGallery()
      } else if (data.status === 'failed') {
        stopPolling(); generating.value = false
        ElMessage.error(data.message || '生成失败')
      } else if (tries >= 40) {                    // 3 秒 × 40 = 2 分钟
        stopPolling(); generating.value = false
        ElMessage.warning('等待超时，请稍后在“已生成场景图”中查看')
      }
    } catch (e) {
      stopPolling(); generating.value = false
      ElMessage.error(e.message)
    } finally { busy = false }
  }, 3000)
}

async function run() {
  if (!productId.value) return ElMessage.warning('请先选择商品')
  generating.value = true
  current.value = null
  try {
    const { data } = await generateImage({ productId: productId.value, sceneIndex: sceneIndex.value })
    current.value = { prompt: data.prompt, scene: data.scene, imageUrl: '' }
    startPolling(data.assetId)
  } catch (e) {
    generating.value = false
    ElMessage.error(e.message)
  }
}

async function loadGallery() {
  const list = (await fetchAssets({ type: 'image' })).data
  gallery.value = list.filter((a) => a.status === 'done')
}

onMounted(() => { store.load(); loadGallery() })
onBeforeUnmount(stopPolling)          // 离开页面必须清除定时器
</script>
```

## 四、常见问题

| 现象 | 处理办法 |
| --- | --- |
| 创建任务返回 `AccessDenied` / 模型无权限 | 在百炼控制台确认已开通通义万相，并且 API Key 属于该业务空间 |
| 创建任务返回 `X-DashScope-Async` 相关错误 | 请求头必须包含 `X-DashScope-Async: enable` |
| 一直 pending 不结束 | 去控制台查看任务状态；超过 5 分钟会被后端标记为超时 |
| 图片打不开，显示链接过期 | 官方链接只保留 24 小时，要在成功后立即下载到本地 |
| 生成的图里有乱码文字 | 在提示词里强调 `no text, no watermark`，并删去提示词中含文字的描述 |
| 商品形状与原图差别很大 | 文生图不会参考原图，只靠文字描述；在提示词里把颜色、材质、形状写得更具体 |
| 轮询请求越堆越多 | 检查 `busy` 标志和 `clearInterval`，以及页面销毁时的清理 |
