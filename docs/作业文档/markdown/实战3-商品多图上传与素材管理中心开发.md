# 实战3-商品多图上传与素材管理中心开发

**多模态 AI 跨境电商智能出海营销工坊**

## 一、作业目标

素材是营销工坊的“原材料”。本次作业要做出资产中心：运营能一次拖入多张商品图、填写商品信息，系统把图片安全地存到服务器、把数据写进 MongoDB，并在列表页以瀑布流展示。完成后你应该能做到：

- 开发带格式与大小校验的拖拽上传组件和商品信息表单；
- 用 multer 实现多文件上传，做到“文件类型、大小、数量、文件名”四项安全约束；
- 把图片路径和商品数据写入 MongoDB，并通过静态目录对外访问；
- 用瀑布流卡片渲染商品图文列表。

> 提示：
>
> 文件上传是常见的安全风险点。不要信任用户给的文件名和扩展名，也不要把图片存进可执行目录。本次要用“随机文件名 + 白名单类型 + 大小限制”来兜底。

## 二、功能与接口一览

| 功能 | 前端 | 后端接口 |
| --- | --- | --- |
| 上传商品 | 拖拽上传 + 信息表单，提交 multipart/form-data | POST /api/products |
| 商品列表 | 瀑布流卡片，展示首图、名称、受众、品类 | GET /api/products |
| 删除商品（选做） | 卡片右上角删除按钮 | DELETE /api/products/:id |
| 访问图片 | `<img src>` 加载图片 | GET /uploads/文件名（静态资源） |

## 三、操作步骤

### 步骤 1　后端：配置 multer 上传中间件

1. 新建 `server/src/middlewares/upload.js`，设置存储位置、文件名、类型白名单和大小限制：

```js
import multer from 'multer'
import path from 'path'
import fs from 'fs'
import { randomUUID } from 'crypto'
import { fileURLToPath } from 'url'

const __dirname = path.dirname(fileURLToPath(import.meta.url))
export const UPLOAD_DIR = path.resolve(__dirname, '../../uploads')
fs.mkdirSync(UPLOAD_DIR, { recursive: true })

const ALLOWED = { 'image/jpeg': '.jpg', 'image/png': '.png', 'image/webp': '.webp' }

const storage = multer.diskStorage({
  destination: (req, file, cb) => cb(null, UPLOAD_DIR),
  // 不使用用户原始文件名，避免路径穿越与重名覆盖
  filename: (req, file, cb) => cb(null, randomUUID() + ALLOWED[file.mimetype]),
})

export const uploadImages = multer({
  storage,
  limits: { fileSize: 5 * 1024 * 1024, files: 5 },   // 单张 5MB，最多 5 张
  fileFilter: (req, file, cb) => {
    if (!ALLOWED[file.mimetype]) {
      const err = new Error('仅支持 JPG / PNG / WebP 图片')
      err.status = 400
      err.code = 4001
      return cb(err)
    }
    cb(null, true)
  },
}).array('images', 5)
```

2. 在 `app.js` 中开放上传目录为静态资源（放在 `app.use('/api', routes)` 之前）：

```js
import { UPLOAD_DIR } from './middlewares/upload.js'
// ...
app.use('/uploads', express.static(UPLOAD_DIR))
```

3. multer 的限制错误（如文件过大）默认不会带 status，需要在 `app.js` 的统一错误处理里补一段转换：

```js
app.use((err, req, res, next) => {
  if (err.name === 'MulterError') {
    const map = { LIMIT_FILE_SIZE: '单张图片不能超过 5MB', LIMIT_FILE_COUNT: '最多上传 5 张图片',
                  LIMIT_UNEXPECTED_FILE: '上传字段名应为 images' }
    return res.status(400).json({ code: 4001, message: map[err.code] || err.message })
  }
  console.error('[error]', err)
  res.status(err.status || 500).json({ code: err.code || 5001, message: err.message || '服务器内部错误' })
})
```

说明：

校验放在后端才是真正的安全保障。前端的校验只是为了让用户少等、少出错，随时可以被绕过。

### 步骤 2　后端：商品创建与列表接口

1. 新建 `server/src/controllers/productController.js`：

```js
import Product from '../models/Product.js'

export async function createProduct(req, res, next) {
  try {
    const { name, audience = '', category = '' } = req.body
    if (!name?.trim()) return res.status(400).json({ code: 4001, message: '商品名称不能为空' })
    if (!req.files?.length) return res.status(400).json({ code: 4001, message: '请至少上传一张图片' })

    const images = req.files.map((f) => '/uploads/' + f.filename)
    const product = await Product.create({ name, audience, category, images })
    res.json({ code: 0, message: 'ok', data: product })
  } catch (e) { next(e) }
}

export async function listProducts(req, res, next) {
  try {
    const page = Math.max(parseInt(req.query.page) || 1, 1)
    const size = Math.min(parseInt(req.query.size) || 20, 50)
    const [list, total] = await Promise.all([
      Product.find().sort({ createdAt: -1 }).skip((page - 1) * size).limit(size),
      Product.countDocuments(),
    ])
    res.json({ code: 0, message: 'ok', data: { list, total, page, size } })
  } catch (e) { next(e) }
}
```

2. 在 `src/routes/index.js` 中注册路由：

```js
import { uploadImages } from '../middlewares/upload.js'
import { createProduct, listProducts } from '../controllers/productController.js'

router.post('/products', uploadImages, createProduct)
router.get('/products', listProducts)
```

3. 用 Postman 或 Apifox 测试：POST `http://localhost:3000/api/products`，Body 选 form-data，字段 name（Text）和 images（File，可多选），应返回 `code: 0` 与商品数据。

4. 再用 GET `/api/products` 验证能取回，用浏览器直接访问 `http://localhost:3000/uploads/文件名` 能看到图片。

> 注意：`uploads/` 目录已在 `.gitignore` 中，图片不会进入 Git，这是正常的。

2. 新建 `client/src/stores/product.js`，用 Pinia 管理列表：

```js
import { defineStore } from 'pinia'
import { ref } from 'vue'
import { fetchProducts } from '../api/product'

export const useProductStore = defineStore('product', () => {
  const list = ref([])
  const loading = ref(false)

  async function load() {
    loading.value = true
    try {
      const res = await fetchProducts({ page: 1, size: 50 })
      list.value = res.data.list
    } finally {
      loading.value = false
    }
  }
  return { list, loading, load }
})
```

### 步骤 4　前端：拖拽上传组件与商品表单

1. 新建 `client/src/components/UploadPanel.vue`，包含表单和拖拽区域：

```vue
<script setup>
import { reactive, ref } from 'vue'
import { ElMessage } from 'element-plus'
import { createProduct } from '../api/product'

const emit = defineEmits(['created'])
const form = reactive({ name: '', audience: '', category: '' })
const fileList = ref([])
const submitting = ref(false)

const ALLOWED = ['image/jpeg', 'image/png', 'image/webp']
const MAX_MB = 5

// 选择文件时校验：不合格就拒绝加入列表
function beforeAdd(rawFile) {
  if (!ALLOWED.includes(rawFile.type)) {
    ElMessage.error('仅支持 JPG / PNG / WebP 图片')
    return false
  }
  if (rawFile.size > MAX_MB * 1024 * 1024) {
    ElMessage.error(`单张图片不能超过 ${MAX_MB}MB`)
    return false
  }
  return true
}
function onChange(file, files) {
  if (!beforeAdd(file.raw)) fileList.value = files.filter((f) => f.uid !== file.uid)
  else fileList.value = files
}
function onExceed() { ElMessage.warning('最多上传 5 张图片') }

async function submit() {
  if (!form.name.trim()) return ElMessage.warning('请填写商品名称')
  if (!fileList.value.length) return ElMessage.warning('请至少选择一张图片')
  const fd = new FormData()
  Object.entries(form).forEach(([k, v]) => fd.append(k, v))
  fileList.value.forEach((f) => fd.append('images', f.raw))   // 字段名需与后端一致
  submitting.value = true
  try {
    await createProduct(fd)
    ElMessage.success('上传成功')
    form.name = form.audience = form.category = ''
    fileList.value = []
    emit('created')
  } catch (e) {
    ElMessage.error(e.message)
  } finally {
    submitting.value = false
  }
}
</script>

<template>
  <el-card header="上传商品素材">
    <el-form :model="form" label-width="80px">
      <el-form-item label="商品名称" required><el-input v-model="form.name" maxlength="60" /></el-form-item>
      <el-form-item label="目标受众">
        <el-select v-model="form.audience" placeholder="请选择" clearable style="width: 100%">
          <el-option v-for="a in ['欧美年轻人','日本上班族','拉美家庭用户','东南亚学生']" :key="a" :label="a" :value="a" />
        </el-select>
      </el-form-item>
      <el-form-item label="商品品类">
        <el-select v-model="form.category" placeholder="请选择" clearable style="width: 100%">
          <el-option v-for="c in ['家居收纳','3C 配件','美妆个护','服饰箱包','户外运动']" :key="c" :label="c" :value="c" />
        </el-select>
      </el-form-item>
      <el-form-item label="商品图片" required>
        <el-upload drag multiple :auto-upload="false" :limit="5" accept=".jpg,.jpeg,.png,.webp"
                   list-type="picture" v-model:file-list="fileList" :on-change="onChange" :on-exceed="onExceed">
          <div>将图片拖到此处，或 <em>点击选择</em></div>
          <template #tip><div>支持 JPG / PNG / WebP，单张不超过 5MB，最多 5 张</div></template>
        </el-upload>
      </el-form-item>
      <el-form-item><el-button type="primary" :loading="submitting" @click="submit">上传并保存</el-button></el-form-item>
    </el-form>
  </el-card>
</template>
```

2. 在 `App.vue` 中引入组件并监听 `created` 事件刷新列表（下一步一起完成）。

> 提示：`el-upload` 的 `auto-upload` 设为 false，是因为我们要把“表单字段 + 多张图片”合并成一次 FormData 请求，而不是让它每选一张就单独上传。

## 四、常见问题

| 现象 | 处理办法 |
| --- | --- |
| 后端收到的 req.files 为空 | 前端 append 的字段名必须是 images，且用 file.raw，不能直接传 el-upload 的文件对象 |
| 图片裂开、加载不出 | 检查 VITE_API_BASE 与路径拼接；浏览器直接访问 /uploads/文件名 看后端是否返回 |
| Postman 上传报 LIMIT_UNEXPECTED_FILE | form-data 的文件字段名要写 images |
| 上传后列表不刷新 | 确认 emit('created') 触发，且 listRef.reload() 被调用 |
| 瀑布流卡片被截断到两列 | 给 .item 加 break-inside: avoid |
| 上传接口返回 413 | 本地开发一般不会出现，部署到 Nginx 后要设置 client_max_body_size（作业 9 处理） |
