# 实战2-全栈工程骨架搭建与数据库初始化

**多模态 AI 跨境电商智能出海营销工坊**

## 一、作业目标

本次作业把作业 1 的“图纸”变成一个能跑起来的“空壳工程”：
前端、后端、数据库三者打通，并用 Git 管理起来。
后面 8 次作业都在这个骨架上添砖加瓦，所以目录要规范、配置要干净。
完成后你应该能做到：

- 用 Vite 创建 Vue 3 前端，接入 Element Plus 与环境变量；
- 用 Express 搭建分层的后端，配置跨域与请求体解析；
- 连接 MongoDB，并用 Mongoose 设计 Product 与 MarketingAsset 两个 Schema；
- 前端成功请求后端 /api/health，完成第一次前后端联调；
- 把代码提交到个人 Git 仓库。

> 提示：这一天的目标不是“功能多”，而是“骨架稳”。**路由、控制器、模型**分层清楚了，后面的开发才不会乱。

## 三、操作步骤

### 步骤 1　检查开发环境

1. 打开终端，依次执行下面的命令，确认版本符合要求：
   ```bash
   node -v        # 需要 v20 或更高
   npm -v
   git --version
   ```
2. 准备 MongoDB，三种方式任选其一：
   - 方式 A（推荐，已装 Docker）：执行 `docker run -d --name mongo -p 27017:27017 -v mongo-data:/data/db mongo:7`；
   - 方式 B：在本机安装 MongoDB Community Server，并启动服务；
   - 方式 C：注册 MongoDB Atlas 免费云库，拿到形如 `mongodb+srv://用户:密码@xxx.mongodb.net/aimarketing` 的连接串。
3. 安装 MongoDB Compass（图形化客户端），连接 `mongodb://127.0.0.1:27017`，能看到默认的 admin、local 库即成功。

> 提示：国内网络下 npm install 慢，可先执行 `npm config set registry https://registry.npmmirror.com` 切换国内镜像。

### 步骤 2　创建项目目录并初始化 Git

1. 在你的工作目录执行：
   ```bash
   mkdir ai-marketing-workshop
   cd ai-marketing-workshop
   git init
   ```
2. 新建 .gitignore 文件，内容如下（一定要先建，再提交代码）：
   ```text
   node_modules/
   dist/
   .env
   .env.
   !.env.example
   server/uploads/
   !server/uploads/.gitkeep
   .DS_Store
   .idea/
   .vscode/
   ```
3. 创建上传目录占位文件：`mkdir -p server/uploads && touch server/uploads/.gitkeep`（Windows PowerShell 可用 `New-Item server/uploads/.gitkeep -Force`）。

> 注意：.env 里会放大模型 API Key，绝对不能被提交到仓库。如果不小心提交了，必须立即去控制台删除并重建 Key。

### 步骤 3　初始化前端（Vue 3 + Element Plus）

1. 在项目根目录执行，创建前端工程：
   ```bash
   npm create vite@latest client -- --template vue
   cd client
   npm install
   npm install element-plus pinia axios vue-router echarts
   ```
2. 修改 client/src/main.js，引入 Element Plus 与 Pinia：
   ```js
   import { createApp } from 'vue'
   import { createPinia } from 'pinia'
   import ElementPlus from 'element-plus'
   import 'element-plus/dist/index.css'
   import App from './App.vue'

   createApp(App).use(createPinia()).use(ElementPlus).mount('#app')
   ```
3. 创建环境变量文件。client/.env.development：
   ```text
   VITE_API_BASE=http://localhost:3000
   ```
   client/.env.production（生产环境前后端同域，留空即可，作业 9 会用到）：
   ```text
   VITE_API_BASE=
   ```
4. 新建 client/src/api/http.js，统一封装 axios：
   ```js
   import axios from 'axios'

   const http = axios.create({
     baseURL: import.meta.env.VITE_API_BASE ?? '',
     timeout: 60000,
   })

   // 统一解包 { code, message, data }
   http.interceptors.response.use(
     (res) => {
       const body = res.data
       if (body && body.code !== undefined && body.code !== 0) {
         return Promise.reject(new Error(body.message || '请求失败'))
       }
       return body
     },
     (err) => Promise.reject(new Error(err.response?.data?.message || err.message)),
   )

   export default http
   ```
5. 启动前端：npm run dev，浏览器打开终端提示的地址（默认 <http://localhost:5173），能看到> Vite 默认页面即成功。

> 说明：以后所有请求都通过 http.js 发出，不要在组件里到处写 `axios.get('http://localhost:3000/...')`，否则部署时要改一大片。

### 步骤 4　初始化后端（Express 分层结构）

1. 回到项目根目录，创建后端工程并安装依赖：
   ```bash
   cd ..
   mkdir server && cd server
   npm init -y
   npm install express cors mongoose multer dotenv
   mkdir -p src/config src/routes src/controllers src/services src/models src/middlewares
   ```
2. 打开 server/package.json，增加 "type": "module" 并改写 scripts（Node 20 自带 --watch，无需 nodemon）：
   ```json
   {
     "name": "ai-marketing-server",
     "type": "module",
     "scripts": {
       "dev": "node --watch src/app.js",
       "start": "node src/app.js"
     }
   }
   ```
3. 新建 server/.env 与 server/.env.example（后者只留变量名，可以提交）：
   ```text
   PORT=3000
   MONGO_URI=mongodb://127.0.0.1:27017/aimarketing
   CORS_ORIGIN=http://localhost:5173
   DASHSCOPE_API_KEY=
   ```
4. 新建 src/config/db.js：
   ```js
   import mongoose from 'mongoose'

   export async function connectDB() {
     const uri = process.env.MONGO_URI
     if (!uri) throw new Error('缺少 MONGO_URI 环境变量')
     await mongoose.connect(uri)
     console.log('[db] MongoDB 已连接')
   }
   ```
5. 新建控制器 src/controllers/healthController.js：
   ```js
   export function health(req, res) {
     res.json({
       code: 0,
       message: 'ok',
       data: { status: 'up', time: new Date().toISOString() },
     })
   }
   ```
6. 新建路由 src/routes/index.js，作为所有路由的汇总入口：
   ```js
   import { Router } from 'express'
   import { health } from '../controllers/healthController.js'

   const router = Router()
   router.get('/health', health)

   export default router
   ```
7. 新建入口 src/app.js，配置跨域、请求体解析、路由与统一错误处理：
   ```js
   import 'dotenv/config'
   import express from 'express'
   import cors from 'cors'
   import { connectDB } from './config/db.js'
   import routes from './routes/index.js'

   const app = express()

   app.use(cors({ origin: process.env.CORS_ORIGIN?.split(',') || '*' }))
   app.use(express.json({ limit: '2mb' }))
   app.use(express.urlencoded({ extended: true }))

   app.use('/api', routes)

   // 统一错误处理：必须放在所有路由之后
   app.use((err, req, res, next) => {
     console.error('[error]', err)
     res.status(err.status || 500).json({
       code: err.code || 5001,
       message: err.message || '服务器内部错误',
     })
   })

   const port = process.env.PORT || 3000
   connectDB()
     .then(() => app.listen(port, () => console.log(`[server] http://localhost:${port}`)))
     .catch((e) => {
       console.error('[启动失败]', e.message)
       process.exit(1)
     })
   ```
8. 在 server 目录执行 npm run dev，终端应看到“MongoDB 已连接”和“<http://localhost:3000”。再在浏览器访问> <http://localhost:3000/api/health，应返回> JSON。

### 步骤 5　设计 MongoDB 数据模型

1. 新建 server/src/models/Product.js：
   ```js
   import mongoose from 'mongoose'

   const productSchema = new mongoose.Schema(
     {
       name: { type: String, required: true, trim: true },
       audience: { type: String, default: '' },          // 目标受众
       category: { type: String, default: '' },          // 品类
       images: [{ type: String }],                       // 图片相对路径，如 /uploads/xxx.png
       aiAnalysis: {                                     // 作业 4 回写
         visual_elements: [String],
         core_selling_points: [String],
         scene_suggestions: [String],
         analyzedAt: Date,
       },
     },
     { timestamps: true }
   )

   export default mongoose.model('Product', productSchema)
   ```
2. 新建 server/src/models/MarketingAsset.js：
   ```js
   import mongoose from 'mongoose'

   const assetSchema = new mongoose.Schema(
     {
       productId: { type: mongoose.Schema.Types.ObjectId, ref: 'Product', required: true, index: true },
       type: { type: String, enum: ['copy', 'image'], required: true },
       language: String,                                 // en / ja / es
       channel: String,                                  // amazon / tiktok / instagram
       content: String,                                  // 文案正文
       imageUrl: String,                                 // 场景图路径
       prompt: String,                                   // 生图提示词
       taskId: String,                                   // 生图异步任务 ID
       status: { type: String, enum: ['pending', 'done', 'failed'], default: 'done' },
     },
     { timestamps: true }
   )

   export default mongoose.model('MarketingAsset', assetSchema)
   ```
3. 为了验证模型可用，临时在 app.js 的 app.listen 之前写一小段（验证完删除），或新建 server/src/seed-check.js，用 `Product.create({ name: '测试商品' })` 插入一条数据。
4. 打开 Compass，刷新 aimarketing 库，应能看到 products 集合和刚插入的文档。验证后用 Compass 删除这条测试数据。

> 说明：`timestamps: true` 会自动生成 createdAt 和 updatedAt，后面看板统计按天聚合会用到。

### 步骤 6　前后端联调 /api/health

1. 新建 client/src/api/health.js：
   ```js
   import http from './http'

   export const getHealth = () => http.get('/api/health')
   ```
2. 把 client/src/App.vue 改成下面这样，页面加载时调用接口并在控制台打印：
   ```vue
   <script setup>
   import { ref, onMounted } from 'vue'
   import { getHealth } from './api/health'

   const status = ref('检测中...')

   onMounted(async () => {
     try {
       const res = await getHealth()
       console.log('[health] 后端响应：', res)
       status.value = '后端连接成功：' + res.data.time
     } catch (e) {
       console.error('[health] 请求失败：', e.message)
       status.value = '后端连接失败：' + e.message
     }
   })
   </script>

   <template>
     <el-card style="max-width: 560px; margin: 60px auto">
       <h2>AI 出海营销工坊</h2>
       <el-tag :type="status.includes('成功') ? 'success' : 'info'">{{ status }}</el-tag>
     </el-card>
   </template>
   ```
3. 同时开着前端和后端，刷新页面，按 F12 打开浏览器控制台（Console），应能看到 \[health] 后端响应：{ code: 0, ... }。这就是提交物 2 的截图内容。

## 四、常见问题

| **现象**                                       | **处理办法**                                                      |
| -------------------------------------------- | ------------------------------------------------------------- |
| 浏览器控制台报 CORS 错误                              | 检查后端 CORS\_ORIGIN 是否包含前端地址（默认 <http://localhost:5173），改完重启后端> |
| 后端启动报 ECONNREFUSED 127.0.0.1:27017           | MongoDB 没启动：Docker 用 docker start mongo；本机安装的用服务管理启动          |
| Cannot use import statement outside a module | server/package.json 缺少 "type": "module"                       |
| 前端请求变成 404                                   | 检查 .env.development 中 VITE\_API\_BASE，修改环境变量后要重启 npm run dev  |
| 端口 3000 被占用                                  | 修改 server/.env 的 PORT，同时改前端 VITE\_API\_BASE                   |
| git push 要求登录失败                              | Gitee 用账号密码或私人令牌，GitHub 必须使用 Personal Access Token            |
| .env 被提交了                                    | 立即 git rm --cached server/.env 并重新提交，同时去控制台更换其中的 Key          |
