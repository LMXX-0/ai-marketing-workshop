## 一、作业目标

这是项目里**第一次接入大模型**。我们要让模型“看懂”商品图，并且按照固定的 JSON 格式输出外观、卖点和场景建议，供后续文案与生图使用。完成后你应该能做到：

- 申请并配置大模型 API Key，用环境变量管理密钥；
- 封装一个统一的 `llmClient`，后面所有 AI 调用都复用它；
- 把本地图片转成 Base64 传给多模态模型；
- 用带强约束的 System Prompt 让模型稳定输出纯 JSON，并在后端做容错解析；
- 前端用“AI 一键识别”按钮触发，并用彩色标签展示结果。

> **提示：**大模型输出是不确定的。**不要假设它一定返回合法 JSON**，后端必须有解析容错和失败重试，前端必须有失败提示。

## 二、背景知识

### 2.1 多模态请求长什么样

百炼提供兼容 OpenAI 协议的接口，图片可以用 Base64 的 data URL 放进 `messages` 里：

```json
{
  "model": "qwen-vl-max",
  "messages": [
    { "role": "system", "content": "系统提示词..." },
    { "role": "user", "content": [
        { "type": "image_url", "image_url": { "url": "data:image/png;base64,iVBORw0..." } },
        { "type": "text", "text": "请分析这件商品" }
    ] }
  ]
}
```

### 2.2 目标 JSON 结构

| 字段 | 含义 | 示例 |
| --- | --- | --- |
| `visual_elements` | 商品外观特征：颜色、材质、形状、风格 | `["哑光黑色外壳", "圆角矩形", "磨砂质感"]` |
| `core_selling_points` | 面向海外消费者的核心卖点 | `["超长续航 30 小时", "防水防汗"]` |
| `scene_suggestions` | 适合展示商品的海外生活场景 | `["清晨公园晨跑，阳光洒在身上"]` |

### 步骤 2　封装统一的大模型客户端 llmClient

1. 新建 `server/src/services/llmClient.js`。后面所有文本、识图调用都从这里走，作业 6 会加流式，作业 8 会加 Token 埋点：

```js
const BASE = process.env.LLM_BASE_URL || 'https://dashscope.aliyuncs.com/compatible-mode/v1'

export class LLMError extends Error {
  constructor(message, status = 502) {
    super(message)
    this.status = status
    this.code = 5002
  }
}

/**
 * 非流式对话。返回 { content, usage, model }
 * purpose 用于标记调用用途（vision / copy / prompt），作业 8 用来做统计
 */
export async function chatCompletion({ model, messages, temperature = 0.7, purpose = 'chat', timeoutMs = 90000 }) {
  const key = process.env.DASHSCOPE_API_KEY
  if (!key) throw new LLMError('服务器未配置 DASHSCOPE_API_KEY', 500)

  const res = await fetch(`${BASE}/chat/completions`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json', Authorization: `Bearer ${key}` },
    body: JSON.stringify({ model, messages, temperature }),
    signal: AbortSignal.timeout(timeoutMs),
  }).catch((e) => { throw new LLMError('大模型请求失败：' + e.message) })

  const data = await res.json().catch(() => ({}))
  if (!res.ok) throw new LLMError(`大模型返回 ${res.status}：${data.error?.message || '未知错误'}`)

  return {
    content: data.choices?.[0]?.message?.content ?? '',
    usage: {
      promptTokens: data.usage?.prompt_tokens ?? 0,
      completionTokens: data.usage?.completion_tokens ?? 0,
    },
    model: data.model || model,
    purpose,
  }
}
```

2. 注意错误信息里**不要拼接 Key**，也不要把完整请求头打印到日志。

**说明：**Node 20 自带全局 `fetch`，不需要再安装 axios 或 node-fetch。

### 步骤 3　编写视觉分析服务与 System Prompt

1. 新建 `server/src/services/visionService.js`。先看提示词，这是本次作业的核心，要把约束写死：

```js
export const VISION_SYSTEM_PROMPT = `你是一名资深跨境电商商品分析专家。请观察用户提供的商品图片，输出商品分析结果。

【输出规则】
1. 只输出一个合法的 JSON 对象，不要输出任何解释文字，不要使用 Markdown 代码块；
2. JSON 必须且只能包含以下三个字段，字段值均为字符串数组：
   - "visual_elements"：商品外观特征（颜色、材质、形状、风格、包装等），3 到 6 条；
   - "core_selling_points"：面向海外消费者的核心卖点（功能与利益点），3 到 5 条；
   - "scene_suggestions"：适合展示该商品的海外生活场景，3 条，每条是一句完整的场景描述；
3. 每条内容不超过 30 个汉字；
4. 只描述图片中能看到或能合理推断的内容，禁止编造具体参数、认证、销量、价格；
5. 如果图片无法识别为商品，三个字段都返回空数组。

【输出示例】
{"visual_elements":["哑光黑色外壳","圆角矩形"],"core_selling_points":["便携轻巧","简约百搭"],"scene_suggestions":["清晨的咖啡馆窗边，阳光洒在木桌上"]}`
```

2. 在同一个文件里继续编写图片转码、JSON 容错解析与分析函数：

```js
import fs from 'fs'
import path from 'path'
import { UPLOAD_DIR } from '../middlewares/upload.js'
import { chatCompletion } from './llmClient.js'

const MIME = { '.jpg': 'image/jpeg', '.png': 'image/png', '.webp': 'image/webp' }

// 把本地图片转成 data URL（只取文件名，防止路径穿越）
function toDataUrl(relPath) {
  const file = path.join(UPLOAD_DIR, path.basename(relPath))
  const mime = MIME[path.extname(file).toLowerCase()] || 'image/png'
  return `data:${mime};base64,${fs.readFileSync(file).toString('base64')}`
}

// 容错解析：去掉 ```json 围栏，截取第一个 { 到最后一个 }
export function extractJson(text) {
  const cleaned = text.replace(/```json|```/gi, '').trim()
  const start = cleaned.indexOf('{')
  const end = cleaned.lastIndexOf('}')
  if (start < 0 || end < start) throw new Error('模型输出中没有 JSON')
  return JSON.parse(cleaned.slice(start, end + 1))
}

const toArr = (v) => (Array.isArray(v) ? v.map(String).filter(Boolean) : [])

export async function analyzeProduct(product) {
  const imgs = product.images.slice(0, 3).map((p) => ({
    type: 'image_url', image_url: { url: toDataUrl(p) },
  }))
  const userText = `商品名称：${product.name}；品类：${product.category || '未填写'}；目标受众：${product.audience || '未填写'}。请分析这件商品。`

  for (let attempt = 1; attempt <= 2; attempt++) {         // 解析失败最多重试 1 次
    const { content, usage } = await chatCompletion({
      model: process.env.VISION_MODEL || 'qwen-vl-max',
      messages: [
        { role: 'system', content: VISION_SYSTEM_PROMPT },
        { role: 'user', content: [...imgs, { type: 'text', text: userText }] },
      ],
      temperature: 0.2,                                    // 结构化输出用低温度
      purpose: 'vision',
    })
    console.log(`[vision] 第 ${attempt} 次原始输出：`, content.slice(0, 200), usage)
    try {
      const json = extractJson(content)
      return {
        visual_elements: toArr(json.visual_elements),
        core_selling_points: toArr(json.core_selling_points),
        scene_suggestions: toArr(json.scene_suggestions),
      }
    } catch (e) {
      if (attempt === 2) {
        const err = new Error('大模型返回格式异常，请重试')
        err.status = 502; err.code = 5002
        throw err
      }
    }
  }
}
```

> **提示：**识图是“按图片大小计费”的，所以只取前 3 张图。调试阶段尽量用较小的图片，省额度也快。

### 步骤 4　新增“AI 识别”接口

```js
在 productController.js 中追加：
import { analyzeProduct } from '../services/visionService.js'

export async function analyze(req, res, next) {
  try {
    const product = await Product.findById(req.params.id).catch(() => null)
    if (!product) return res.status(404).json({ code: 4004, message: '商品不存在' })

    const result = await analyzeProduct(product)
    product.aiAnalysis = { ...result, analyzedAt: new Date() }
    await product.save()
    res.json({ code: 0, message: 'ok', data: product.aiAnalysis })
  } catch (e) { next(e) }
}
在路由中注册：router.post('/products/:id/analyze', analyze)。
```

import { analyzeProduct } from '../api/product'

const analyzing = reactive({})   // 每个商品各自的 loading 状态

async function runAnalyze(p) {

## 四、常见问题

| 现象 | 处理办法 |
| --- | --- |
| 返回 401 / `InvalidApiKey` | Key 复制不完整或有空格；确认 `.env` 修改后已重启后端 |
| 返回 400，提示图片格式或大小问题 | 图片过大时先压缩到 2MB 以内再试；确认 data URL 前缀 `data:image/png;base64,` 拼写正确 |
| 返回 404 / 模型不存在 | `VISION_MODEL` 写错，到模型广场复制模型名 |
| 返回 429 | 请求太快或额度用尽，稍等再试，并查看控制台额度 |
| 解析 JSON 失败 | 看后端日志里模型的原始输出，调整提示词；确认 `extractJson` 处理了代码块围栏 |
| 识别结果和商品不符 | 换一张主体清晰、背景干净的图；在用户消息里补充商品名与品类 |
| 前端一直转圈 | 看后端终端报错；axios 超时时间已设为 60 秒，可适当调大 |
