## 多模态 AI 跨境电商智能出海营销工坊：实战 5-多语言营销文案生成引擎开发

# 一、作业目标

有了作业 4 提取的卖点，这一步要把它们变成**面向不同语言、不同平台**的爆款文案。同一个商品，在 Amazon 上要写规范的标题和五点描述，在 TikTok 上要写短视频脚本，在 Instagram 上要有 Emoji 和 Hashtag。完成后你应该能做到：

- 设计渠道与语言配置，把“渠道调性”写成可维护的配置；
- 搭建 Prompt 模板引擎，把商品卖点、目标语言、发布渠道三个参数拼装成高质量提示词；
- 调用文本大模型生成文案；
- 编写敏感词与极端营销词的拦截中间件，做合规兜底。

**提示：**好文案 = 好 Prompt。模板把“角色、任务、约束、格式”四件事讲清楚，输出质量会稳定很多。本次作业的重点是**模板设计**，不是界面。

### **步骤 2　搭建 Prompt 模板引擎**

1. 新建 server/src/services/promptBuilder.js，把三个参数拼成 messages：

```js
import { LANGUAGES, CHANNELS } from '../config/channels.js'

export function buildCopyMessages({ product, language, channel, extra = '' }) {
  const lang = LANGUAGES[language]
  const ch = CHANNELS[channel]
  if (!lang) throw Object.assign(new Error('不支持的目标语言'), { status: 400, code: 4001 })
  if (!ch) throw Object.assign(new Error('不支持的发布渠道'), { status: 400, code: 4001 })

  const a = product.aiAnalysis || {}
  const system = `You are a senior cross-border e-commerce copywriter.
Write the final copy ONLY in ${lang}. Do not add any explanation outside the copy.
Hard rules:
- Use only the facts provided. Never invent specifications, certifications, prices or statistics.
- Avoid absolute or exaggerated claims such as "best", "No.1", "100% guaranteed", "miracle", "cure".
- Keep the tone natural for local consumers, not a literal translation.
Channel requirements:
${ch.spec}`

  const user = `Product name: ${product.name}
Appearance: ${(a.visual_elements || []).join('; ') || 'N/A'}
Key selling points: ${(a.core_selling_points || []).join('; ') || 'N/A'}
${extra ? 'Extra requirements: ' + extra : ''}
Please write the ${ch.label} copy now.`

  return [{ role: 'system', content: system }, { role: 'user', content: user }]
}
```

### **步骤 3　敏感词与极端营销词拦截中间件**

1. 新建 server/src/middlewares/compliance.js。这里分两层：输入拦截（拒绝）和输出处理（遮蔽并提示）：

```js
// 极端营销词、绝对化用语、医疗功效类词汇（可按需继续扩充）
const BANNED = [
  /最(好|佳|强|低|高|大|优|先进)/g, /第一/g, /顶级|极致|史上|万能/g, /100%|百分之百/g,
  /根治|治愈|包治|药效|永久/g, /国家级|唯一/g,
  /\b(best in the world|no\.?\s?1|guaranteed|miracle|cure[sd]?|risk[- ]free)\b/gi,
]

export function findViolations(text = '') {
  const hits = new Set()
  for (const re of BANNED) {
    re.lastIndex = 0
    const m = text.match(re)
    if (m) m.forEach((w) => hits.add(w))
  }
  return [...hits]
}

export function maskViolations(text = '') {
  return BANNED.reduce((t, re) => t.replace(re, (w) => '*'.repeat(w.length)), text)
}

// 输入拦截：用户自己填写的补充要求里出现违规词，直接拒绝
export function inputGuard(fields = ['extra']) {
  return (req, res, next) => {
    for (const f of fields) {
      const hits = findViolations(req.body?.[f] || '')
      if (hits.length) {
        return res.status(400).json({ code: 4003, message: `补充要求包含敏感或极端营销词：${hits.join('、')}` })
      }
    }
    next()
  }
}
```

### **步骤 4　文案生成服务与接口**

1. 新建 server/src/services/copyService.js：

```js
import { chatCompletion } from './llmClient.js'
import { buildCopyMessages } from './promptBuilder.js'
import { findViolations, maskViolations } from '../middlewares/compliance.js'

export async function generateCopy({ product, language, channel, extra }) {
  const messages = buildCopyMessages({ product, language, channel, extra })
  const { content, usage } = await chatCompletion({
    model: process.env.TEXT_MODEL || 'qwen-plus',
    messages,
    temperature: 0.8,
    purpose: 'copy',
  })
  const warnings = findViolations(content)     // 输出层检测
  return { content: maskViolations(content), warnings, usage }
}
```

2. 新建 server/src/controllers/copyController.js：

```js
import Product from '../models/Product.js'
import { generateCopy } from '../services/copyService.js'

export async function generate(req, res, next) {
  try {
    const { productId, language, channel, extra } = req.body
    const product = await Product.findById(productId).catch(() => null)
    if (!product) return res.status(404).json({ code: 4004, message: '商品不存在' })
    if (!product.aiAnalysis?.core_selling_points?.length)
      return res.status(400).json({ code: 4001, message: '请先对该商品执行“AI 一键识别”' })
    const data = await generateCopy({ product, language, channel, extra })
    res.json({ code: 0, message: 'ok', data })
  } catch (e) { next(e) }
}
```

# 四、常见问题

| **现象**                       | **处理办法**                                                 |
| ------------------------------ | ------------------------------------------------------------ |
| 生成结果夹着中文解释           | System Prompt 中强调“ONLY in 目标语言，不要在文案之外添加解释” |
| Amazon 的 Bullet 数量不是 5 条 | 规格里写成 “exactly 5 bullets”，必要时降低 temperature 至 0.5 |
| 日语出现中文词汇               | 在语言配置里写明“です・ます調”，并要求使用自然的日本本地表达 |
| 提示“请先执行 AI 一键识别”     | 文案依赖作业 4 的卖点，先去资产中心识别该商品                |
| 敏感词没被拦住                 | 用 findViolations('这是最好的产品') 单独测试正则，注意 g 标志位导致的 lastIndex 问题 |
| 同一个请求每次结果差别很大     | 调低 temperature，并把格式要求写得更具体                     |

# 五、自检清单

- 渠道与语言配置集中在 channels.js，新增一个渠道只需改配置；
- Prompt 模板同时接收卖点、目标语言、发布渠道三个参数；
- System Prompt 包含角色、事实边界、禁用词、格式要求；
- 输入层与输出层都有合规拦截，且你自己扩充了敏感词；
- 三种渠道的结果在结构与调性上能明显区分；
- 日语、西班牙语输出语言正确；
- 前端能选商品、语言、渠道，并显示结果与敏感词提示。
